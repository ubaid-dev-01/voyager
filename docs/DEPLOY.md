# Deploy — voyager

## Vercel project
- Name: `voyager`
- GitHub: https://github.com/ubaid-dev-01/voyager

## CLI
```bash
cd voyager-main
vercel --prod --yes
```

## Pipeline
1. Native Git: `vercel git connect https://github.com/ubaid-dev-01/voyager.git`
2. GitHub Actions: set secrets `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`
