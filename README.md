## Overview

Voyager is a Next.js travel brand experience covering destinations, vacation rentals, travel styles, technology story, testimonials, FAQ, and request/contact flows, plus a dashboard shell.

## Features

- Destination and rental marketing pages
- Travel styles and case study surfaces
- Request / contact funnels
- Dashboard shell
- Motion-led branding with Framer Motion

## Architecture

App Router pages under `src/app`. Prefer server components for content pages; keep interactive islands client-side.

## Tech stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- pnpm

## Project structure

```text
voyager-main/
├── src/app/
├── src/components/

```

pnpm dev
